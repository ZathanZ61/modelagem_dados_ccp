# modelagem_dados_ccp

# 📚 Estudos de Banco de Dados e SQL

Repositório destinado aos estudos e à prática da disciplina **Banco de Dados**, do curso de **Ciência da Computação**.

O objetivo é reunir exercícios, exemplos práticos e códigos SQL desenvolvidos durante o aprendizado, construindo um material de consulta e evolução dos conhecimentos.

## 🎯 Objetivos

- Compreender os conceitos fundamentais de Banco de Dados.
- Aprender modelagem de dados e relacionamentos.
- Entender o funcionamento de um SGBD.
- Praticar comandos SQL.
- Desenvolver consultas e manipulação de dados.
- Registrar a evolução dos estudos por meio de exercícios práticos.

## 📖 Conteúdos estudados

- Fundamentos de Banco de Dados.
- Banco de Dados Relacional.
- Sistemas Gerenciadores de Banco de Dados (SGBD).
- Modelagem conceitual, lógica e física.
- Entidades, atributos e relacionamentos.
- Cardinalidade: 1:1, 1:N e N:N.
- Chave Primária (PRIMARY KEY).
- Chave Estrangeira (FOREIGN KEY).
- Linguagem SQL.
- DDL, DML, DQL, DCL e TCL.
- INSERT, UPDATE e DELETE.
- SELECT e consultas.
- WHERE, AND, OR e ORDER BY.
- DISTINCT, LIKE, BETWEEN e IN.
- Funções de agregação.
- GROUP BY e HAVING.
- JOIN e relacionamentos entre tabelas.
